# AI HVAC Diagnostic Copilot

An interactive demo that shows how AI and workflow automation can support HVAC service operations, troubleshooting, technician communication, and service data logging.

## Live Workflow

Service Request  
→ Request Intake  
→ Customer Email  
→ AI Diagnostic Agent  
→ Dispatcher Alert  
→ Technician Assignment  
→ Google Sheets Record

## Features

- Interactive HVAC service request demo
- AI-assisted diagnostic workflow
- Customer acknowledgement email
- Dispatcher notification
- Technician job assignment
- Google Sheets service record
- Animated workflow visualization
- Play / Pause / Replay controls
- Edit Mode with draggable and resizable workflow nodes
- Dynamic connection lines between workflow components

## Tech Stack

- HTML
- CSS
- JavaScript
- n8n
- Claude AI
- Telegram
- Google Sheets

## Purpose

This project explores how HVAC troubleshooting knowledge can be combined with AI and automation to help organize service requests, support diagnostic reasoning, improve technician communication, and structure service data.

## Demo Note

The diagnostic probabilities and service data shown in the animation are simulated for demonstration purposes and should not be considered a definitive HVAC diagnosis.
